Workspace and startup

              
How do I start and stop the Windows app?
Double-click the Windows JAR and keep its launcher window open. Press Q in that window to stop. Your events stay in the Omnistream-data folder beside the JAR.

              
How does Groq connect?
The Windows launcher reads the server-side GROQ_API_KEY environment variable or a credential encrypted for your Windows account. With neither available, it starts the local rules parser. Restart the launcher after changing the credential.

              
How do I send events from another app?
Send JSON with sourceId, eventType, and rawPayload to POST /api/v1/events/ingest. Use your service’s X-API-KEY header. A 202 response contains the event ID. Open API reference.
